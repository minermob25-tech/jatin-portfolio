# Jatin Sharma Portfolio

## Run
npm install
npm run dev

## Photo
Put your photo at `public/profile.jpg`.

The image has:
- cursor-following 3D tilt
- elastic jiggle on hover/touch
- cyan glow
- scanline effect
- slight zoom

## Build
npm run build
